mend is one command-line patch tool for every AI edit format. It applies unified diffs (including ones with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls to a tree of text files, exactly as SPEC.md specifies: three-tier matching that finds the named lines even when whitespace or indentation has drifted, re-indentation of replacement text at the drift tiers, and all changes or none — a failed patch writes nothing. It passes all 100 public practice checks (practice score 1000).

## Run it

```sh
node main.ts [options] [PATCH]
```
